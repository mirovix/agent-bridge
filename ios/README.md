# Native iOS client

This directory contains the SwiftUI iPhone and iPad application. Login,
sessions, chat, prompts, jobs, folders, voice recording, photos, settings, 2FA,
and persistent cookies are native views. HappyDEV uses a bundled local
`WKWebView`; external Reels content uses a protected browser view.

Open `AgentBridge.xcodeproj` in Xcode to build it. For signing, GitHub Actions,
SideStore, TestFlight, and simulator instructions, see
**[iPhone installation](../docs/INSTALL_IOS.md)**.
